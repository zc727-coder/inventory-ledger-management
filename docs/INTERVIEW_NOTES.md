# 面试说明

## 一分钟项目介绍

这是一个面向仓储台账管理的前后端分离系统。我主要解决的是库存当前状态与历史流水一致性的问题：商品主表保存当前库存，出入库操作写入带商品快照的流水表；再通过按月分表控制台账数据规模。系统同时提供权限控制、Excel 导入导出、条码扫码、图片管理和统计看板。

## 可展开的技术点

| 主题 | 可以说明的实现 |
| --- | --- |
| 鉴权 | JWT 负责令牌校验，Redis 保存可失效的会话数据，拦截器把轻量用户信息放入当前请求上下文。 |
| 库存一致性 | 出入库校验库存，更新商品当前库存并追加流水；流水保存商品名称、规格、库位等快照。 |
| 分表 | 登录日志和库存流水按 `yyyy_MM` 路由到月表；表名由后端正则校验，Mapper XML 负责动态 SQL。 |
| 文件与表格 | 图片只保存 URL/路径，Excel 使用模板导入导出，下载流不包装为普通 JSON。 |
| 可观测性 | AOP 记录请求和服务耗时；日志输出前对敏感字段做掩码。 |

## 诚实边界

- 项目以本地/虚拟机环境验证为主，不宣称高并发压测或生产规模数据。
- 密码、地址、日志、上传文件和构建产物均不进入仓库。
- 演示时建议准备一组脱敏的商品、出入库和统计数据。
